notes
  • 主色：■ cyan #00e5ff ■ magenta #ff2fd6 ■ lime #baff29 ■ amber #ffb347 ■ danger #ff355a
  • 字体：纯 monospace。macOS 上 "SF Mono"；可选 JetBrains Mono 作为 ship font。
  • 外壳：2 层 bevel（亮上暗下边框）+ inset shadow，复刻 Winamp classic skin 的金属边。
  • LCD 区：scanline + 微 cyan glow，呈现 CRT 质感；文字带 text-shadow 做霓虹。
  • PLAY/PAUSE/STOP：SVG 三角 / 双竖条 / 方块，hover 时按颜色分别 glow。Idle 时 Pause/Stop 半透明；Running 时 Play 半透明。
  • Phase segments：LED 方块阵，当前阶段数量亮 magenta/cyan，代表推进度（跟 PRD §5 的 phase 序列对应）。
  • Progress panel：从 transport 下方滑入。包含 6 个 LED 风格大数字（Elapsed/Tokens/Last activity/Round/Failures/Cost）+ 左右分栏 Timeline & Raw。
  • Timeline 行按 outcome 上色：ok=lime，fail=danger，note=amber。Raw stream 里 JSON key 高亮 cyan，usage 数字高亮 magenta。
  • Cost 行是附加项，用 Claude Code stream-json 的 total_cost_usd 字段；不需要的话可以去掉。
